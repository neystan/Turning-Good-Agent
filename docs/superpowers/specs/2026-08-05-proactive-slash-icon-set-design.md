# Proactive Slash 图标扩展设计

状态：用户已确认视觉方向，待书面规范复核后实施。

## 1. 目标

为 Agent 产品新增四枚独立的 Slash 命令小图标：

- 压缩
- dream
- breakbeat（待办事项）
- skill 沉淀

它们复用当前 Slash 面板的图标槽与视觉语言，只显示在命令项左侧；不添加背景、文字、底板或颜色作为语义区分。

## 2. 通用规范

- 每枚图标均为透明背景的 24×24 SVG，默认使用 `stroke="currentColor"`。
- 线宽为 1.9，端点和转角均使用圆角。
- UI 内的实际渲染尺寸为 16px，图形保留至少约 2px 的画布边距。
- 每枚 SVG 同时导出一张 64×64 RGBA 透明 PNG，供静态预览与非 React 使用。
- 浏览器运行时优先使用 SVG mask，使图标在深色、浅色、悬停和选中状态中继承当前文字色。

## 3. 图标语义

### 压缩

使用用户确认的 C1“双向压实”：上下两组箭头共同指向中央的核心横线。它表示把冗长对话的上下文压缩为短而可继续工作的记忆，不把图形误导为删除、筛选或文件打包。

### dream

保留 A 方案：新月加一颗小能力星。它表示暂时进入发散、联想和探索性的构思模式，而不是睡眠、暂停或普通夜间模式。

### breakbeat

保留 A 方案：三行待办清单，每行均有已勾选的节拍点。它表示把下一步行动拆成可推进的待办事项，避免采用音频节拍器或暂停按钮等歧义图形。

### skill 沉淀

使用用户确认的 S1“知识入库”：打开的 Skill 手册向下进入一条存储基线。它表示将重复工作流写为可复用的 Skill，而不是普通附件归档、数据库备份或单纯保存文件。

## 4. 交付与集成

在 `web/frontend/src/assets/slash-icons/` 新增：

- `compress.svg`
- `dream.svg`
- `breakbeat.svg`
- `skill-deposit.svg`

在 `web/frontend/public/slash-icons/` 新增同名 PNG。

扩展前端命令图标联合类型与 `SlashCommandMenu` 的资源映射；命令目录为新增命令返回对应 icon 值。除新增命令的图标资源和映射外，不改变面板的读取、筛选、键盘导航、选择或命令行为。

## 5. 验收

1. 四枚 SVG 具有透明背景、24×24 viewBox 和统一的线性视觉重量。
2. 四枚 PNG 均为 64×64 RGBA，四角 alpha 为零。
3. 在 16px 下，压缩与 skill 沉淀仍可分别被理解为“收束为记忆”和“工作流固化为 Skill”。
4. dream 与 breakbeat 延续已确认的 A 方案，且不与已有查看、工具、MCP、Skill 图标混淆。
5. 深浅主题中，图标继承当前文字色且 Slash 面板既有行为测试通过。
