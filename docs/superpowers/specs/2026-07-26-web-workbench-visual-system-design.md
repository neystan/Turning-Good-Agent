# Web Workbench Visual System Design

状态：待用户审阅。

## 目标

在不改变 Runtime、Session、Memory、Tool、MCP、REST、WebSocket 与 JSON/JSONL 边界的前提下，完成 Turning-Good-Agent Web 工作台的第二轮视觉与交互重构。

本轮不迁入 Fluent、Material 或其他完整设计系统。采用“自定义工作台视觉 + Radix 交互基础组件”的方式：Radix 处理菜单、对话框、确认框、Tooltip 与 Switch 的可访问性和焦点行为；TGA 保留自己的 Token、布局、聊天体验与观测表达。

## 设计定位

Reading this as: 本机个人 Agent 工作台，面向高频任务执行用户，采用克制、可信的石墨灰控制台语言，偏向紧凑的对话优先产品界面。

| 参数 | 值 | 含义 |
| --- | --- | --- |
| `DESIGN_VARIANCE` | 4 | 维持稳定三栏与对话结构，不使用营销式构图。 |
| `MOTION_INTENSITY` | 2 | 仅使用状态反馈、菜单和抽屉过渡。 |
| `VISUAL_DENSITY` | 7 | 支持高频扫描，但不把聊天流做成日志大屏。 |

## 范围

### 包含

1. 统一深浅主题 Token、组件层级、圆角、边框、文字和状态色。
2. 会话菜单、搜索、重命名、删除确认和 Tooltip 迁移到 Radix Primitive。
3. 将“完全访问权限”改为明确的工具审批策略 Switch。
4. 重排任务活动簇，使其按照真实发生顺序位于 user 消息与 assistant 消息之间。
5. 修复检查器打开时消息被遮挡的问题，并重做检查器摘要与详情层级。
6. 保留并加强独立滚动、键盘、焦点、减少动态偏好和移动端安全区域。

### 不包含

1. 不引入 Tailwind、shadcn、Fluent、Material 或完整 UI Kit。
2. 不新增 WebSocket 事件、持久化文件、监控数据或模型 reasoning 展示。
3. 不修改 AgentLoop、Runtime、MCP、Tool、安全审批规则或后端 API。
4. 不增加营销页、插画、渐变背景、图片资产或装饰性动效。

## 交互基础组件

新增最小 Radix 依赖，保留 `lucide-react` 作为唯一图标库：

| Primitive | 替换目标 | 说明 |
| --- | --- | --- |
| `DropdownMenu` | 会话三点菜单 | 自动 Portal、键盘导航、视口碰撞规避与外部关闭。 |
| `AlertDialog` | 删除会话确认 | 处理焦点捕获、Escape、取消与危险动作。 |
| `Dialog` | 重命名与会话搜索 | 处理模态语义、焦点回归和移动端对话框。 |
| `Tooltip` | 所有图标按钮 | 统一悬浮提示和可访问名称。 |
| `Switch` | 自动批准策略 | 表达二元审批策略，不再伪装成“权限等级”。 |

现有 `OverlayPortal` 在上述迁移完成后删除。`SessionInspector` 桌面端继续是非模态的固定检查器，移动端使用现有全屏覆盖语义，不将观测阅读变成阻塞对话的模态流程。

## 视觉 Token

### 色彩

使用冷中性石墨灰阶，唯一非状态操作强调为柔和蓝色。深浅模式必须维持相同语义。

| 语义 | 深色 | 浅色 | 用途 |
| --- | --- | --- | --- |
| 页面 | `#121417` | `#f6f7f9` | 页面背景。 |
| 一级表面 | `#191c21` | `#ffffff` | 侧栏、顶部栏、检查器。 |
| 二级表面 | `#20242a` | `#f1f3f6` | Hover、输入框底栏、低层菜单。 |
| 边框 | `#303640` | `#d9dee6` | 结构分隔，不制造卡片堆叠。 |
| 主文字 | `#edf0f4` | `#1e232b` | 正文与标题。 |
| 次文字 | `#9ca5b3` | `#697586` | 元信息和辅助说明。 |
| 操作蓝 | `#7aa2f7` | `#386fca` | 发送、键盘焦点、当前操作。 |
| 等待审批 | `#d9a441` | `#956308` | 仅表示需要用户确认。 |
| 完成 | `#6fc49f` | `#267a57` | 完成状态。 |
| 失败 | `#e06c75` | `#ba3e4a` | 停止、失败与删除。 |

连接成功不使用高亮状态色，保持次级灰色。运行状态使用操作蓝，审批使用琥珀色，避免将“已连接”“运行中”“需要确认”混为一类。

### 形状与文字

1. 按钮、输入、菜单和小型浮层使用 `6px` 圆角；确认对话框和检查器使用 `8px` 圆角。
2. 阴影只用于覆盖层和菜单，使用低透明度石墨阴影；普通区域通过边框和留白分组。
3. 保留本地中文系统字体栈，不下载远程字体。常规文字使用比例字体，数字、Token、Trace 计数使用等宽字体与 `tabular-nums`。
4. 删除 `LOCAL AGENT` 等无任务价值的装饰性标签。空态只保留标题、说明和输入入口。

## 信息架构与组件行为

### 侧栏

1. 新建会话保持为唯一显式命令；搜索使用图标按钮和 Tooltip。
2. 会话标题左对齐，置顶图标、运行标识和三点操作固定在右侧槽位。三点仅在 hover、键盘聚焦或当前会话显示。
3. 会话菜单按“置顶、重命名、归档、删除”排列，删除前有分隔线并使用危险色。菜单不显示多余标题。
4. 对话框不使用浏览器原生 `confirm`。删除确认明确说明本地会话及记录将被永久删除。

### 聊天与任务活动簇

1. 同一 turn 的渲染顺序为：user 消息、`ActivityCluster`、assistant 消息。活动簇只消费已有真实事件。
2. 运行时活动簇默认展开，主标题优先显示最新真实动作，例如“正在调用 weather”“正在加载 Skill”“正在等待工具审批”。没有可显示动作时才使用“思考中”。
3. 结束后活动簇短暂停留，再收为单行摘要：`已完成，4 秒，调用 1 个工具`。点击可查看受限高度的真实步骤时间线。
4. 审批请求嵌入该 turn 的活动簇，显示工具名、规范化参数、拒绝和允许一次。它不是通用 Toast，也不能被其他 turn 淹没。
5. 不显示、推断、保存或伪造模型 reasoning、思维链和计划文本。

### Composer 与工具审批

1. Composer 保持与消息列相同的左边界和最大宽度。输入高度自动增长，最大高度不超过 `220px`。
2. 空闲状态占位文本为“发送消息…”，运行中为“补充当前任务方向…”。Enter 发送，Shift+Enter 换行。
3. 将下拉中的“默认权限 / 完全访问权限”改为 `工具审批` Switch：
   - 关闭：`每次工具操作都需要确认`。
   - 打开：`自动批准后续工具操作`。
   - 固定辅助说明：`安全限制始终生效`。
4. Switch 仅改变后续审批点；当前已经显示的审批卡必须等待用户操作。运行中的 Stop 保持与发送按钮同一位置和宽度。

### 检查器

1. 桌面端检查器固定在右侧，主会话不使用位移动画。
2. 打开检查器后，消息列保持当前左侧锚点，只收紧右侧可用宽度，使任何 user 或 assistant 消息都不会进入检查器覆盖区域。Composer 使用同一可见安全区。
3. 检查器先呈现累计输入、累计输出、当前上下文、压缩次数和工具失败等摘要；数值使用 `Intl.NumberFormat`。
4. Token、压缩与上下文、工具调用、状态 Trace 使用可折叠结构化条目。原始 JSON 只在单个条目的“查看原始记录”中出现，且不作为默认阅读内容。
5. 关闭检查器后恢复完整聊天可用宽度，但不改变用户当前滚动位置。

## 可访问性与动效

1. 所有图标按钮必须具有 `aria-label`、Tooltip 和 `:focus-visible`。
2. `Dialog`、`AlertDialog` 和 `DropdownMenu` 使用 Radix 的焦点、Escape、外部关闭和焦点回归行为。
3. 异步错误与操作反馈由 `NoticeRegion` 以 `aria-live="polite"` 呈现。
4. 仅过渡 `opacity` 与 `transform`，持续状态仅允许加载图标旋转；`prefers-reduced-motion` 下完全静止。
5. 侧栏、聊天、活动步骤、检查器、菜单和模态层保持独立滚动，并设置 `overscroll-behavior: contain`。

## 验收标准

1. 删除、重命名、搜索、三点菜单和权限策略不再使用手写点击外部监听或浏览器原生确认框。
2. 右侧检查器打开时，没有消息、输入框、发送或 Stop 按钮被遮挡。
3. 活动簇的事件顺序与真实任务发生顺序一致，且不展示 reasoning。
4. 深色与浅色模式的操作、审批、完成与失败语义一致，文字、按钮和输入框满足可读对比度。
5. 通过前端相关测试、`npm run build`、`pytest -q`、`git diff --check`、REST/WebSocket 冒烟；具备 Chromium 时补充桌面与移动端 Playwright 截图审查。
