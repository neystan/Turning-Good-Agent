# Slash Command 小图标设计

状态：视觉方向已由用户确认，待书面规范复核后实施。

## 1. 目标

为 Composer 输入 `/` 时出现的 Slash Command 面板设计四枚独立小图标：

- MCP
- 工具
- 查看
- Skill

图标只承担命令类型识别，不包含文字、面板、底板或品牌字标。成品必须适合当前面板的 20px 图标槽，并在 16–18px 实际显示尺寸下保持清晰。

## 2. 视觉系统

- 使用统一的 24×24 viewBox。
- 采用单色线性图标，默认 `stroke="currentColor"`。
- 主线宽为 1.9，端点与转角使用圆角。
- 默认不使用固定色、渐变、阴影、发光或背景容器。
- SVG 画布透明；PNG 导出保持 RGBA 透明背景。
- 图形在 24×24 画布内保留约 2px 安全边距，视觉重量与现有 Lucide 图标接近。
- 图标不依赖文字，在深色与浅色主题中均由界面文字色驱动。

## 3. 四枚图标语义

### MCP

使用三个圆形节点构成稳定三角关系，并以三条短线连接。它表达多个外部能力通过统一协议建立连接，同时避免与普通插头、网络状态或分享图标混淆。

### 工具

使用简化扳手轮廓。扳口、柄部和末端保持单一连续结构，表达可执行工具，并与项目当前的工具语义保持一致。

### 查看

使用眼睛轮廓与中央瞳孔。它表达只读查看或检查，区别于设置、搜索与执行动作。

### Skill

使用打开的知识手册，并在右页上方加入一颗小型四角能力星。手册表达可加载的知识与指导，能力星区分普通帮助文档；该方案为用户选择的 S3。

## 4. 交付物

创建独立目录 `web/frontend/src/assets/slash-icons/`，交付：

- `mcp.svg`
- `tools.svg`
- `inspect.svg`
- `skill.svg`

同时在 `web/frontend/public/slash-icons/` 导出透明 PNG：

- 每枚图标提供 64×64 PNG，供非 React 场景或视觉验收使用。
- PNG 图形使用中性浅色线条，以便在透明背景检查器和当前暗色 Slash 面板中预览。

前端集成时优先使用 SVG；PNG 不作为 React 组件的默认运行时资源。

## 5. 集成边界

- 只替换 `SlashCommandMenu` 左侧的命令类型图标。
- 不改变 Slash 命令数据、过滤、键盘导航、选择行为、面板布局或接口契约。
- 不在图标后增加方形、圆形或渐变底板。
- MCP、工具、查看和 Skill 必须映射为四种不同图形，不能以颜色作为唯一差异。

## 6. 验收

1. 四枚 SVG 均为 24×24 viewBox，背景透明并使用 `currentColor`。
2. 在 16px、18px 和 24px 三种尺寸下无明显糊边、断线或结构粘连。
3. 在深色和浅色主题中具有足够对比度。
4. 隐去文字后，四枚图标仍能相互区分。
5. Skill 图标在 16px 下仍能看出“打开的手册”，能力星不会与页面轮廓粘连。
6. Slash 面板的行为测试保持通过。
